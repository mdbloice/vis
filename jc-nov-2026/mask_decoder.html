A segmentation mask is just a picture

The model is asked to paint each class in an agreed colour. A simple rule turns the painted image back into labels: every pixel gets the class whose prompted colour is closest. Hover over any image to inspect a pixel, and use the sliders to make the model's painting less perfect.

Prompt: "Generate a semantic segmentation visualization image, using this color mapping: {"sky": <0, 90, 255>, "tree": <0, 170, 0>, "car": <255, 0, 0>, "road": <128, 128, 128>, "background": <255, 220, 0>}"
